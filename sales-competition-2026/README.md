# תחרות המכירות 2026

סרטון אנכי נפרד לעובדי הסוכנות. הוא לא מחובר למערכת הקיימת.

הקובץ המוכן לשליחה בוואטסאפ:

`dist/sales-competition-2026.mp4`

1080×1920, 60 שניות, H.264 ו־AAC. בלי קריינות, בלי דמויות ובלי אווטארים.

## שינוי טקסטים, יעדים או פרסים

כל הנוסח יושב ב־`content.json`. אחרי שמירה מריצים:

```bash
npm install
npm run render
```

צריך Node, Google Chrome ו־FFmpeg מקומיים. אין שירות חיצוני ואין מנוי.

`npm run check` מוודא שהמשפטים מהבריף נשארו שלמים ושהסצנות מתחברות ל־60 שניות.

`npm run preview` פותח את הסרטון בדפדפן לפני ייצוא. `npm run stills` שומר תמונות בדיקה ב־`dist/qa`.

## החלפת תמונת מוצר

שמים קובץ PNG שקוף בתיקייה `assets/products` באחד השמות:

- `ps5.png`
- `ninja.png`
- `camera.png`
- `iphone-18-pro-max.png`
- `galaxy-s26.png`

ואז מריצים `npm run render`. בלי קובץ, נשארת במת המוצר המקורית.

PlayStation 5, סט הנינג'ה והמצלמה מצוירים כאיור מקורי עם השם המדויק. דגם המצלמה ודגם הסט לא נמסרו, ולכן לא מופיע שם דגם.

iPhone 18 Pro Max ו־Samsung Galaxy S26 מוצגים כבמת פרס עם השם המדויק, לא כתצלום של מכשיר אחר.

## לוגו, גופן ומוזיקה

הלוגו המקורי נמצא ב־`assets/logo/gemel-logo.png`. מחליפים את הקובץ בלי למתוח אותו, או משנים את הנתיב בשדה `logo`.

הגופן הוא Heebo במסגרת רישיון SIL Open Font License, בקובץ `assets/fonts`.

המוזיקה נוצרת במחשב על ידי `audio/synthesize.mjs`: פסקול מקורי בלי מילים, באורך הסרטון, עם דגש על חיתוכי הסצנות ועל הופעת היעדים.
