# Walkthrough — F1.3 מילוי תיק פתוח קודם

תיק שפתוח עכשיו מתמלא ראשון (`ensureRecordPayload` / תור עדיפות). אצל נציג רגיל שאר התיקים ממשיכים להתמלא ברקע — בלי זה מסך המכירות נתקע על «טוען».

במאגר גדול / מנהל צוות: עדיין בלי מילוי המוני; אם יש תיק פתוח — רק הוא מתמלא.

לא שינינו כניסה, UI, או דלתא. בדיקה: סנכרון + כניסה, ואז פתיחת תיק לקוח.
