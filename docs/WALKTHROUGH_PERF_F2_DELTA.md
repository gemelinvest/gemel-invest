# Walkthrough — F2 דלתא רזה

סנכרון חי (`loadSheetsDelta`) שולף רק עמודות רשימה ללקוחות ולהצעות — לא `select("*")`.

`payload` שכבר בזיכרון נשמר במיזוג. תיק שנפתח עדיין נמשך ב־`ensureRecordPayload`. אצל נציג רגיל המילוי ברקע נשאר.

לא שינינו כניסה, UI, או קצב LiveRefresh. בדיקה: סנכרון + כניסה, ואז פתיחת תיק לקוח.
